Станції прокату: містять велосипеди

Велосипеди: бувають звичайні або електричні, мають власний номер

Клієнт: імʼя, баланс рахунку; може взяти велосипед, кататись певну кількість часу, повернути на будь-яку станцію, має мати велосипед 

Адмін бачить велосипеди на станціях, скільки грошей зароблено загалом
